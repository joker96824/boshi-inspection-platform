# 博实智能巡检平台 - 快速部署指南

**适用系统**: 麒麟、Ubuntu、Debian、CentOS  
**部署时间**: 约5分钟

---

## 一、安装Docker环境

### 麒麟/Ubuntu/Debian系统

```bash
# 安装Docker
sudo apt update
sudo apt install docker.io docker-compose -y

# 启动Docker服务
sudo systemctl start docker
sudo systemctl enable docker

# 添加当前用户到docker组（可选）
sudo usermod -aG docker $USER
# 执行后需重新登录，或运行: newgrp docker
```

### CentOS/RHEL系统

```bash
# 安装Docker
sudo yum install docker docker-compose -y

# 启动Docker服务
sudo systemctl start docker
sudo systemctl enable docker
```

### 验证安装

```bash
docker --version
docker compose version
```

### 配置镜像源（可选，国内环境推荐）

如果镜像拉取速度慢，可以配置国内镜像源（以下为示例）：

```bash
# 编辑Docker配置
sudo nano /etc/docker/daemon.json

# 添加以下内容：
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://registry.cn-hangzhou.aliyuncs.com"
  ]
}

# 保存后重启Docker
sudo systemctl restart docker
```

**注意**：不同镜像源可能需要测试，选择速度最快的。

## 二、部署应用

### 1. 解压

```bash
# 如果是压缩包先解压
unzip boshi-inspection-deploy.zip
```

### 2. 准备目录

```bash
mkdir -p logs scripts
mv init_database.sql scripts/ 2>/dev/null || true
```

### 3. 加载镜像

```bash
docker load -i boshi-inspection-platform-1.0.tar
```

### 4. 启动服务

```bash
docker compose up -d
```

### 5. 等待启动（约30秒）

```bash
sleep 30
docker compose ps
```

### 6. 验证部署

```bash
curl http://localhost:8000/api/v1/system/health
```

**成功标志**: 返回 `{"code":200,"message":"系统健康检查成功",...}`

## 附：特殊说明

### API文档启用/禁用

**文档地址**: `http://服务器IP:8000/docs`

**控制方式**: 修改 `.env` 中的 DEBUG 属性

```yaml
DEBUG=true   # true=启用文档, false=禁用文档（生产环境推荐）
```

修改后重启服务：
```bash
docker compose down
docker compose up -d
```

**说明**：
- `DEBUG: "true"` - 启用API文档（开发/测试环境）
- `DEBUG: "false"` - 禁用API文档（生产环境，更安全）

### 使用外部数据库（高级配置）

**适用场景**：连接服务器本地已安装的MySQL或外部服务器，而不使用Docker内置MySQL

**修改步骤**：

#### 1. 修改 .env 文件
找到 `DATABASE_URL` 这一行，将 `@mysql` 改为 `@localhost`：

```bash
# 修改前
DATABASE_URL=mysql+aiomysql://boshi:Xx147258.@mysql:3306/boshirobot

# 修改后
DATABASE_URL=mysql+aiomysql://boshi:Xx147258.@localhost:3306/boshirobot
```

或根据需求改为指定的链接和端口

#### 2. 修改 docker-compose.yml 文件（第63-70行）

在 `TZ: Asia/Shanghai` 下方添加一行，并注释端口和网络配置：

```yaml
      TZ: Asia/Shanghai
    network_mode: "host"  # ← 添加这行
    # ports:  # ← 注释掉
    #   - "8000:8000"
    volumes:
      - ./logs:/app/logs
      - ./docs:/app/docs:ro
    # networks:  # ← 注释掉
    #   - boshi-network
```

#### 3. 注释 depends_on（第33-35行）

```yaml
    # depends_on:  # ← 注释掉
    #   mysql:
    #     condition: service_healthy
```

#### 4. 重启服务

```bash
# 停止所有服务
docker compose down

# 只启动app和redis（不启动mysql容器）
docker compose up -d app redis

# 等待启动
sleep 30

# 验证
curl http://localhost:8000/api/v1/system/health
```

**前提条件**：
- ✅ 服务器已安装MySQL并运行
- ✅ 已创建 boshirobot 数据库
- ✅ 已创建 boshi 用户并授权

**切换回Docker内置MySQL**：
1. 将 .env 中的 `@localhost` 改回 `@mysql`
2. 恢复 docker-compose.yml 的注释（取消 network_mode，恢复 ports 和 networks）
3. 执行 `docker compose up -d`
