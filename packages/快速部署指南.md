# 博实智能巡检平台 - 快速部署指南

**适用系统**: 麒麟、Ubuntu、Debian、CentOS  
**部署时间**: 约5分钟

---

## 一、安装Docker环境

### 麒麟/Ubuntu/Debian系统

```bash
# 安装Docker
sudo apt update
sudo apt install docker.io docker-compose -y

# 启动Docker服务
sudo systemctl start docker
sudo systemctl enable docker

# 添加当前用户到docker组（可选）
sudo usermod -aG docker $USER
# 执行后需重新登录，或运行: newgrp docker
```

### CentOS/RHEL系统

```bash
# 安装Docker
sudo yum install docker docker-compose -y

# 启动Docker服务
sudo systemctl start docker
sudo systemctl enable docker
```

### 验证安装

```bash
docker --version
docker compose version
```

### 配置镜像源（可选，国内环境推荐）

如果镜像拉取速度慢，可以配置国内镜像源（以下为示例）：

```bash
# 编辑Docker配置
sudo nano /etc/docker/daemon.json

# 添加以下内容：
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://registry.cn-hangzhou.aliyuncs.com"
  ]
}

# 保存后重启Docker
sudo systemctl restart docker
```

**注意**：不同镜像源可能需要测试，选择速度最快的。

## 二、准备外部数据库

### ⚠️ 重要提示

本系统使用**外部数据库**，不再在 Docker 容器中运行数据库服务。部署前请确保：

1. ✅ **已安装并运行 MySQL 或 PostgreSQL**
2. ✅ **已创建数据库**（如 `boshirobot`）
3. ✅ **已创建数据库用户并授权**
4. ✅ **已执行数据库初始化脚本**

### 1. 创建数据库（MySQL 示例）

```bash
# 连接到 MySQL
mysql -u root -p

# 创建数据库
CREATE DATABASE IF NOT EXISTS boshirobot 
DEFAULT CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;

# 创建用户（可选，也可以使用 root）
CREATE USER 'boshi'@'%' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON boshirobot.* TO 'boshi'@'%';
FLUSH PRIVILEGES;
EXIT;
```

### 2. 初始化数据库表结构

```bash
# 执行初始化脚本
mysql -u boshi -p boshirobot < init_database.sql

# 执行示例数据脚本（可选）
mysql -u boshi -p boshirobot < init_sample_data.sql
```

**PostgreSQL 用户**：需要将 SQL 脚本转换为 PostgreSQL 语法，或使用 PostgreSQL 版本的初始化脚本。

## 三、部署应用

### 1. 解压部署包

```bash
# 如果是压缩包先解压
unzip boshi-inspection-deploy.zip
cd boshi-inspection-deploy
```

### 2. 配置环境变量

```bash
# 复制环境变量示例文件
cp .env.example .env

# 编辑 .env 文件，配置数据库连接
nano .env
```

**必须修改的配置**：

```env
# 数据库连接（根据实际情况修改）
DATABASE_URL=mysql+aiomysql://用户名:密码@数据库主机:3306/数据库名

# 示例：连接本地数据库
DATABASE_URL=mysql+aiomysql://boshi:password123@localhost:3306/boshirobot

# 示例：连接远程数据库
DATABASE_URL=mysql+aiomysql://boshi:password123@192.168.1.100:3306/boshirobot

# 如果使用 PostgreSQL
# DATABASE_URL=postgresql+asyncpg://boshi:password123@192.168.1.100:5432/boshirobot
```

**如果数据库在宿主机上**，还需要设置：

```env
# 使用 host 网络模式访问宿主机数据库
NETWORK_MODE=host
```

### 3. 准备目录

```bash
mkdir -p logs scripts
mv init_database.sql scripts/ 2>/dev/null || true
```

### 4. 加载镜像

```bash
docker load -i boshi-inspection-platform-1.0.tar
```

### 5. 启动服务

```bash
docker compose up -d
```

### 6. 等待启动（约30秒）

```bash
sleep 30
docker compose ps
```

### 7. 验证部署

```bash
curl http://localhost:8000/api/v1/system/health
```

**成功标志**: 返回 `{"code":200,"message":"系统健康检查成功",...}`

### 8. 查看日志

```bash
# 查看应用日志
docker compose logs -f app

# 如果启动失败，检查数据库连接
docker compose logs app | grep -i "database\|error"
```

## 附：特殊说明

### API文档启用/禁用

**文档地址**: `http://服务器IP:8000/docs`

**控制方式**: 修改 `.env` 中的 DEBUG 属性

```yaml
DEBUG=true   # true=启用文档, false=禁用文档（生产环境推荐）
```

修改后重启服务：
```bash
docker compose down
docker compose up -d
```

**说明**：
- `DEBUG: "true"` - 启用API文档（开发/测试环境）
- `DEBUG: "false"` - 禁用API文档（生产环境，更安全）

### 数据库连接问题

**问题**：应用无法连接到数据库

**排查步骤**：

1. **检查数据库服务是否运行**
```bash
# MySQL
systemctl status mysql
# 或
mysql -u root -p -e "SELECT 1"

# PostgreSQL
systemctl status postgresql
# 或
psql -U postgres -c "SELECT 1"
```

2. **检查网络连接**
```bash
# 测试数据库端口是否可达
telnet 数据库主机 3306  # MySQL
telnet 数据库主机 5432  # PostgreSQL
```

3. **检查 .env 配置**
```bash
# 确认 DATABASE_URL 配置正确
cat .env | grep DATABASE_URL
```

4. **检查防火墙**
```bash
# 如果数据库在远程服务器，确保防火墙允许连接
# Ubuntu/Debian
sudo ufw allow 3306/tcp  # MySQL
sudo ufw allow 5432/tcp  # PostgreSQL
```

5. **查看应用日志**
```bash
docker compose logs app | grep -i "database\|error\|connection"
```

### 使用 PostgreSQL

**配置步骤**：

1. **修改 .env 文件**
```env
# 将 MySQL URL 改为 PostgreSQL URL
DATABASE_URL=postgresql+asyncpg://用户名:密码@主机:5432/数据库名
```

2. **初始化 PostgreSQL 数据库**
```bash
# 创建数据库
psql -U postgres -c "CREATE DATABASE boshirobot;"

# 执行初始化脚本（需要先转换为 PostgreSQL 语法）
psql -U postgres -d boshirobot -f init_database_postgresql.sql
```

3. **重启服务**
```bash
docker compose restart
```
